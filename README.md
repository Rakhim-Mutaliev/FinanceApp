# Finance

Finance — личный журнал доходов. В репозитории находятся:

- нативное приложение для iPhone на SwiftUI (`FinanceApp`);
- устанавливаемая веб-версия PWA (`web`), визуально и функционально повторяющая приложение.

## Веб-версия

PWA работает как статический сайт и не использует серверную базу, аккаунт, аналитику, рекламу, API или облачную синхронизацию.

- Доходы хранятся в **IndexedDB** текущего профиля Safari.
- Валюта и оформление хранятся в **localStorage**.
- После первого открытия файлы интерфейса сохраняются Service Worker для офлайн-запуска.
- Content Security Policy запрещает приложению `fetch`, XHR и подключения к внешним доменам.
- Резервная копия создаётся локально как JSON-файл; восстановление читает выбранный пользователем файл локально.

Важно: для первого открытия страницы GitHub Pages интернет нужен. При открытии размещённого сайта браузер и GitHub технически получают обычный HTTP-запрос, но финансовые записи в этот запрос не включаются и код приложения никуда их не отправляет. После установки приложение можно использовать офлайн.

## Функции

- обзор текущего года, средний доход и лучший месяц;
- графики по годам и месяцам;
- добавление, редактирование и удаление месячных записей;
- светлая, тёмная и системная темы;
- RUB, USD и EUR, включая локальный пересчёт истории по заданному курсу;
- печать общего и годового отчёта (на iPhone: «Поделиться» → сохранить PDF);
- экспорт и восстановление JSON-резервной копии;
- полное удаление локальной истории;
- автономный запуск после первой загрузки.

## Публикация на GitHub Pages

Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) публикует папку `web` при каждом push в `main`.

1. На GitHub откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь завершения `Publish Finance PWA`.
4. Ссылка появится в настройках Pages и в результате workflow.

## Установка на iPhone

1. Откройте ссылку GitHub Pages именно в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран “Домой”», затем «Добавить».
4. Один раз запустите Finance с нового ярлыка, после чего приложение доступно офлайн.

Не очищайте «Историю и данные сайтов» Safari без свежей резервной копии: это удалит локальную базу. Само удаление ярлыка с домашнего экрана не является надёжным способом удалить данные сайта; для полного удаления используйте кнопку внутри Finance и при необходимости настройки Safari.

## Локальная проверка

Service Worker работает только через HTTPS или localhost:

```bash
python3 -m http.server 8080 --directory web
```

Откройте `http://localhost:8080`.
